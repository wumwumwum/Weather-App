# Weather-App

Provides current weather information.

## Overview

Program a weather application to call on the weather data for a given area.  


## The Project

This weather app was built using the work of jsamborski310 as the base app. I modified the original app to craft an app that suited my needs and purposes. The weatherapi.com API was utlized in order to call weather data. This information includes the current weather only. The app is programmed to pull current temperature, weather description for the day, minimum temperature, maximum tempurature, wind speed, wind direction, sunrise, and sunset. Weather icons make it easy for the traveler to understand weather conditions at a glance.
This is a full width module at present (20260422).

## Tools

* Javascript
* HTML
* CSS
* Bootstrap
* Open Weather API
* Momentjs


## Reason for Creation

I wanted to create a simple project that I could pivot into a daily planner project at a later date. The planner will require additional modules to be created alongside this weather module.


## Current Status_20260422

I have spent approx. 6 hours creating a functional, stripped down, and simple weather app. The app provides a minimalist overview of weather info that would useful in the planning of my day.
